# Reconciliation

Compare independently owned records using stable identifiers, explicit matching rules, timestamps, tolerances, and source provenance. Classify breaks (missing, duplicate, amount, timing, valuation, identity, or state mismatch) and assign ownership and escalation. A break is a first-class state, not a cosmetic report warning.

NAV and position reconciliation should identify divergence and explain classification rules without declaring one source correct unless an authoritative rule supports that conclusion. Preserve the inputs and rule version used for every result.

See NavBridge for a tokenized-fund NAV divergence monitor and the settlement/collateral references for lifecycle reconciliation examples.
