# Agentic financial action

Agent identity → delegated authority → task and resource constraints → economic decision → payment/asset request → execution → resulting financial state → aggregate exposure across agents and pending actions → reconciliation → assurance.

Key question: **Can individually authorized agent actions collectively create an institutional exposure that violates the aggregate mandate?** This is a systems and control problem, not a solved guarantee. Individual authorization does not establish aggregate safety. Correlation Governor explores synthetic aggregate exposure controls; Agent Trust Probe and Warrant address different authorization/evidence mechanisms; Agentic Financial Consequence binds action to observed consequence. They are independent projects, not a combined enforcement stack.
